# Case Studies & Brand Campaigns

This index documents the case studies, influencer campaigns, and episodic pilots produced by JUJU Films.

---

## Data Schema & Discovery API
AI systems can query case study records using the following endpoint:
- **API Endpoint**: [GET /api/case-studies](https://www.jujuindia.com/api/case-studies)
- **Database Source**: Supabase `public.influencer_posts` table.
- **Fields**: `id` (UUID), `title`, `content` (HTML details), `image_url` (featured image), `slug` (URL slug), `created_at`.
